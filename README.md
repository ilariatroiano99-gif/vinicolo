# Vinicolo Vineria

Sito di Vinicolo Vineria, vineria con cucina a Santa Maria Capua Vetere (CE).

Pagina unica statica: `index.html`, le foto in `img/`, i tre giochi in `giochi/`.
Non serve nessun programma sul server, bastano i file.

Il contenuto (menù, carta dei vini, serate, testi) si modifica dal gestionale
del progetto e da lì si riesporta questa cartella.
